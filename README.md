# python list manipulation exercise

## objective

Practice implementing common Python list methods to perform basic data-processing operations.

## description

This project demonstrates the use of fundamental Python list methods for adding, removing, searching, sorting, reversing, copying, and clearing elements from a list.

## list methods

### 1. append()

Adds an item to the end of the list.

### 2. extend()

Adds all elements from another iterable to the list.

### 3. insert()

Inserts an item at a specified index.

### 4. remove()

Removes the first occurrence of an item from the list.

### 5. pop()

Removes and returns the last element of the list.

### 6. index()

Returns the index of the first occurrence of an item.

### 7. count()

Returns the number of times an item occurs in the list.

### 8. sort()

Sorts the list in ascending order.

### 9. reverse()

Reverses the order of the elements in the list.

### 10. copy()

Creates a shallow copy of the list without modifying the original list.

### 11. clear()

Removes all elements from the list.

### 12. merge and deduplicate

Combines two lists into a new list, removes duplicate elements, and preserves the order of their first appearance.
